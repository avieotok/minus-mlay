# פורטל שרשרת האספקה

מערכת מקצה-לקצה לניהול חוסרים ורכש בין המחסן לקנייני שרשרת האספקה — דיווח, טיפול, מעקב, תקשורת ותיעוד. רצה בדפדפן (PWA), עם Google Apps Script כ-Backend.

## שתי אפליקציות, מערכת אחת

| קובץ | למי | מה יש בו |
|------|-----|----------|
| `index.html` | מחסנאים | דיווח חוסר / פגום / אי-התאמה, סריקת ברקוד, מקלדת מק״ט, צילום ותמונות, "הדיווחים שלי", ידיעון |
| `dashboard.html` | קניינים ומנהל | לוח פניות עם סינון, שיוך וסטטוסים, צ'אט פנייה, מחוונים, ידיעון, ייצוא |

## קבצים משותפים

| קובץ | תפקיד |
|------|-------|
| `config.js` | כתובת ה-Web App והטוקן — **המקום היחיד לעדכן** |
| `catalog.js` | קטלוג המק״טים המוטמע (~360KB) |
| `tools.js` | כלי עזר: רשימות, ספר טלפונים, ממיר מטבעות, ממיר שטחים |
| `sw.js` | Service Worker — תמיכה באופליין ומטמון. **בכל גרסה מעלים את `CACHE_VERSION`** |
| `manifest.webmanifest`, `icon*.png`, `favicon.svg` | התקנה למסך הבית |

## מערכת העיצוב

שני הקבצים חולקים את אותם טוקנים ב-`:root`:

```
--ink #0a0b0e   --surface #15171c   --surface2 #1c1f26
--line #242830  --line2 #343a45
--text #f2f4f8  --muted #a8b0bc     --faint #8a929e
--red #e2231a   --amber #f59e0b     --green #22c55e   --gold #d9b56b
--ts            /* מכפיל גודל טקסט: 1 · 1.14 · 1.3 */
```

כל גודל טקסט כתוב כ-`calc(Npx * var(--ts))`, כך שכפתור **אא** בכותרת מגדיל את כל הממשק בבת אחת (נשמר ב-localStorage תחת `afcon_ts`). רצפת הקריאוּת היא 13px.

לשינוי צבע בכל המערכת — מעדכנים את הטוקן ב-`:root` בשני הקבצים.

## עדכון גרסה

1. `sw.js` → העלו את `CACHE_VERSION`.
2. `index.html` → עדכנו את מספר ה-`build` בפינה.

## פרסום

הקבצים סטטיים לחלוטין. מעלים את כולם לריפו ומפעילים GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
